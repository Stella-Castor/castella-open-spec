## 1. 概要と目的
本リポジトリは、対話型AIシステムにおいてユーザーの無音（放置）時間を監視し、**時間経過に伴い非線形（シグモイド状）に発話抽選確率が上昇する確率テーブル**に基づき、当選時にローカルSSDナレッジ、リアルタイムWeb情報、作業記憶プールから自律的に話題をマイニングしてプロアクティブに発話するアーキテクチャを明示・公開するものである。

本技術の私的独占・特許化を防止し、人類の共有知財としてオープンな実装・発展を保護するために公知化する。

## 2. 確率変動型 自律発話トリガールール

| 無言経過時間 | 発話当選確率 ($P$) | 挙動特性 / システムステート |
| :--- | :--- | :--- |
| **1分経過** | **0.5%** ($P=0.005$) | 極低確率（気まぐれな着眼点の自律着火） |
| **2分経過** | **1.0%** ($P=0.010$) | 低確率待機 |
| **3分経過** | **1.5%** ($P=0.015$) | 低確率待機 |
| **4分経過** | **2.0%** ($P=0.020$) | 作業集中ガード期間 |
| **5分経過** | **20.0%** ($P=0.200$) | **【変曲点】** 一服・小休止の気遣い介入開始 |
| **6分経過** | **25.0%** ($P=0.250$) | 話題提供確率上昇 |
| **7分経過** | **30.0%** ($P=0.300$) | 未解決課題・外部ナレッジ掘り起こし |
| **8分経過** | **40.0%** ($P=0.400$) | 高確率介入 |
| **9分経過** | **50.0%** ($P=0.500$) | 超高確率介入 |
| **10分経過** | **100.0%** ($P=1.000$) | **【確定トリガー】** 必ずいずれかの話題でプロアクティブ発話 |

## 3. システムアーキテクチャ

```text
+---------------------------------------------------------------------------------+
|                                リアルタイム監視ループ                           |
|  [マイク入力 / UI操作] ──▶ 無音・無操作時間を計測 (経過時間 t 秒)              |
+---------------------------------------------------------------------------------+
                                      │
                                      ▼
+---------------------------------------------------------------------------------+
|                        確率変動型 抽選ゲート (毎分判定)                         |
|  ・経過時間 t に応じた確率テーブル P(t) を参照                                  |
|  ・random() < P(t) の判定 ──▶ 【当選】 ────────────────────────────┐            |
|                                │ (落選: 次の1分判定まで待機)       │            |
+--------------------------------------------------------------------+------------+
                                                                     │
                                                                     ▼
+---------------------------------------------------------------------------------+
|                    バックグラウンド・自律トピックマイナー                        |
|  [3大ソースから自律選定]                                                        |
|  1. SSDローカルナレッジ (過去メモ・開発ログ・未解決課題)                        |
|  2. リアルタイムWeb検索 (最新技術動向・ニュース・暗号資産価格)                  |
|  3. 直前の作業記憶プール (SharedContext / 直前のコードや画像)                   |
+---------------------------------------------------------------------------------+
                                      │
                                      ▼
+---------------------------------------------------------------------------------+
|                        文脈統合 ＆ 発話生成 (LLM / Gemma)                       |
|  ・マイニングした事実データをプロンプトに注入                                   |
|  ・「ねぇステラ、〜」「そういえばさっきの件だけど…」等の自然な導入生成          |
+---------------------------------------------------------------------------------+
                                      │
                                      ▼
+---------------------------------------------------------------------------------+
|                 音声合成・発話 (TTS) ＆ タイマー完全リセット                    |
|  ・オンメモリTTSで発話 ➔ 無音タイマーを t=0 にリセット ➔ 再び1分目から抽選開始  |
+---------------------------------------------------------------------------------+
